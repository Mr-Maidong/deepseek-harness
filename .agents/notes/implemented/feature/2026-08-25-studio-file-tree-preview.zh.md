# Agent Note: Studio 文件树预览

Status: implemented

[English](2026-08-25-studio-file-tree-preview.md) | 中文

## 问题

Studio 用户需要查看工作区列表中的 Host 文件，同时不能编辑文件，也不能让浏览器直接访问文件系统。

## 曾考虑的替代方案

直接让浏览器访问文件系统会绕过 Host 的路径和大小限制，因此不予采用。通用编辑器暂缓，因为此功能只需要有大小限制的只读预览。

## 决策

目录选择器 browse 能力通过 Host Remote 读取有大小限制的 UTF-8 文本。Client 工作区服务保留 Host 返回的完整路径，并根据扩展名推导显示语言。Studio 将文件条目渲染为可用键盘操作的按钮，通过 owner 回调把携带状态的预览送入中央只读编辑器槽：点击立即发布 `loading` 状态，读取完成后再换为 `ready`（内容与语言）或 `error`。文件树全程保持渲染，读取状态只在悬浮卡片中展示。

Host 负责路径检查、文件类型检查、字节限制和取消。浏览器负责展示与本地化。预览不会写入文件系统，也不会进入会话日志。

## 结果

不支持的扩展名显示为纯文本。读取中和失败状态在悬浮卡片内渲染，文件树不会把自己替换成占位，读取进行期间保持可交互。未来编辑器应通过已有的 `studio.center.editor` 槽注册，而不是增加第二条跨包渲染路径。

## 验证

实现过程中运行了聚焦 TypeScript 检查、directory-picker Host 测试和包构建。发布前仍需运行完整 GUI、Web 回放、文档和实时 GUI 检查。
