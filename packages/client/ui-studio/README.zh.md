# @deepseek-ai/dsh-client-ui-studio

[English](README.md) | 中文

`ui-studio` 提供编辑器式三栏 Studio 框架。它拥有运行时的 `root` 布局，组织导航栏、对话区和灵光池，并提供侧栏与对话插件使用的布局动作服务。

左栏提供工作区、会话导航和当前工作区的只读文件树。中栏保留既有 conversation 的渲染与输入链。右侧灵光池按项目记录待办，支持新建项目、在底部发布待办、勾选完成状态、点击描述进行编辑，以及将单条待办或当前项目发送到聊天框。中部还保留可供后续插件注册的内容座。

面板宽度属于浏览器内的瞬态状态。框架在需要时保持关闭面板挂载，限制拖拽结果在各列范围内，并在视口暂时不足时保留已保存的宽度偏好。`ctx.layout` 将侧栏动作映射到左栏；Studio 没有详情列，因此详情动作不产生变化。

`/client` 入口导出插件主体、注入声明、owner-share 接口和布局服务。`StudioFrame`、几何 store 和列求解器保留在槽注册内部。

## 整体视觉风格

Studio 采用水墨写意风格，融合宋元山水、山海志怪和泼墨写意等元素。界面应像一张安静、克制的任务案台，带有淡淡的卷宗质感，而不是普通的深色控制台或装饰性古风页面。

### 美术基调

整体构图保持冷、疏、静，并通过虚实层次组织内容。蓝黑冷墨、灰青雾气、雾白文字和安静的结构线构成主要画面。内容、控件和面板边界周围保留有意安排的留白，让界面保持呼吸感。红色和深墨色只在需要冲击力的场景中出现，例如当前项、危险操作、中断状态和关键印记。

### 色彩运用

普通界面保持低饱和与冷色调。应用背景、工作区和状态区域使用冷墨与灰青层次；主要内容使用宣纸灰白或雾白；辅助信息使用烟灰。朱砂红用于紧急状态、危险操作和重要印记；邪魅的深墨色用于集中对比，不作为默认大面积底色。避免霓虹色、青色发光、玻璃拟态高光、暖棕色大面积铺陈、渐变按钮和厚重阴影。

### 核心手法

使用“计白当黑”：留白本身承担层级和节奏，不能用连续卡片把空间填满。通过淡墨晕染、断续结构线、轻微纸纹、纤维感和透明度变化制造深度，而不是依赖强边框、阴影或高亮。圆角保持克制，通常为 `0–6px`；大面积胶囊形和光泽表面不属于 Studio 的视觉语言。

### 落地原则

新增视图应明确一个内容层、一个安静的结构层，以及少量清晰的状态标记。优先使用细线、留白、宣纸色表面和淡墨痕迹，避免堆叠卡片与装饰性效果。产品功能名称保持直白，分组标题可以使用“卷宗”“案台”“江湖”等语境词，但不能牺牲理解。键盘操作、可见焦点、对比度、窄栏换行、响应式布局和减少动效仍然是视觉实现的一部分。

## 模型体验

无。Studio 管理浏览器视图状态，并将用户选中的待办文本发送到对话界面；它不组装或发送 provider 请求。

#### KV 缓存影响

无。本包不构造 provider prompt，也不维护 provider 侧缓存状态。

## 已知限制与待办

- **内容座保持可扩展**——Studio 框架不内建代码编辑器或工具坞，这些区域留给后续注册者。
- **无详情列**——详情座为组合而声明，但本布局不渲染它，因此 `ctx.layout.openDetails` 和 `ctx.layout.closeDetails` 不产生变化。
- **几何与灵光池数据是瞬态的**——面板宽度、项目和待办在刷新后恢复初始值，尚未提供浏览器持久化。
- **无窄视口自动折叠**——左栏在窄布局阈值以下仍保持已保存的宽度偏好。
