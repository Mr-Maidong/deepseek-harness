# @deepseek-ai/dsh-client-ui-studio

[English](README.md) | 中文

## 概述

Studio 提供三栏工作区，用于导航会话、浏览当前工作区、预览有大小限制的文本文件、播放工作区中的图片与视频、就地编辑并保存工作区文件，以及管理项目待办。Web 客户端需要编辑器式界面与可编辑文件预览时，应选择此包。文件读取始终经过 Host/Remote 路径，不会让浏览器直接访问文件系统。

<a id="use-this-package"></a>
## 使用本包

当 Web 客户端需要工作区导航、文件树、可编辑源码预览和项目案台时，挂载 Studio。

### 何时选择

当需要编辑器式布局时选择 Studio。当其他布局拥有展示层时，选择较低层的工作区包。

### 最小配置

Web 组合会加载此包，包本身没有用户可配置字段。生成的[配置目录](../../../docs/config-catalog.zh.md)是所有可接受配置字段的完整来源。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

Host 的 directory-picker browse 能力负责校验并限制文本读取。workspace Client 服务将结果映射为预览，并根据扩展名生成语言标签。点击文件会通过 owner 回调发布带状态的预览（`loading` → `ready`/`error`），悬浮卡片自己展示读取状态，文件树保持渲染。StudioFrame 持有预览状态，并通过 `studio.center.editor` 将 PreviewCard 渲染为锚定在输入栏上方的浮卡片；该卡片是按 kind 驱动的万能容器，kind 由一个共享谓词按路径判定，因此文件树、头部搜索与聊天 opener 对同一文件给出同一分类。`image` 与 `video` 是媒体 kind：卡片通过同一个 Remote 自行读取完整字节，用 `blob:` URL 播放并在换文件时撤销该 URL，持久化 store 中只保留路径与媒体类型。没有对应展示面的二进制格式——`pdf`、压缩包、字体、音频——在读取之前就按扩展名拒绝，未知扩展名下解码出非法字节的文本读取同样如此，因此卡片报告的是拒绝，而不是乱码。`code` 撑满标题行与输入栏之间的整列并展示源码；`iframe` 则自行决定尺寸：它的舞台宽度是卡片宽度的 16:9，外壳贴合这块舞台，底边锚定在输入栏上（`anchor-name: --studio-composer`）且不设 top 钉高，因此草稿变高或视口变矮时卡片向上扩展盖住对话标题行，而不是把渲染产物压变形。loading 与 error 文案落在同一块舞台上，所以 HTML 读取完成时卡片不会改变尺寸。打开源文件即打开编辑器，而不是一个需要切换模式的只读视图：卡片通过 workspace-file Remote（`workspaceFiles.readAll`）读取文件完整字节及其携带的版本，并在带行号的缓冲区中显示,光标已就位,无需再点一下即可输入。页面刷新时框架 store 会先从浏览器存储恢复卡片,而会话列表尚未到达,因此这一次读取会等待列表,而不是报出一个需要手动重试的失败;列表到达却没有选中会话时才是真正的失败,并如实报告。`Ctrl+S`（或点击文件名前的圆点：缓冲区与文件不一致时呈金色，一致时呈灰色）携带该版本经 `workspaceFiles.write` 写回，因此读取之后发生变化的文件会被拒绝（`workspace-file/version-conflict`）而不是被覆盖——卡片保留缓冲区并提供重新加载。保存成功后保留写入产生的版本，并通过普通预览读取重新读取该文件，因此框架 store、内容与语言标签保持同一事实来源。卡片同时抑制浏览器原生右键菜单，把该手势留给卡片自身的操作。文件条目保持使用 Host 返回的完整路径。展开一个文件夹会重新读取它，并且展开时会重读它下面所有仍处于展开状态的文件夹，因此折叠过的子树恢复出来的是目录当前的内容；某次重读失败时，屏幕上已有的条目保持不变。

源码文件渲染为文件文本与行号 gutter 并列，行号标出搜索命中的行，以及“引入”气泡引用的行；点击某个行号即引用该行。读取中、失败和内嵌产物状态不带 gutter，行号也不会进入被复制的选区。

工作区搜索位于会话标题行最右侧的工具位（`conversation.session.header.utilities`）：搜索触发钮在其下方右对齐展开一个悬浮结果面板，样式沿用万能预览卡片的 `--studio-*` token 语言并门户挂载进 studio frame 节点，底层是 Host 的 ripgrep 纯文本搜索（`remote.workspace.search`）。查询有防抖，回车立即搜索，单调请求号加 AbortController 保证只有最新请求的结果会落地。结果的文件路径是完全限定的 Host 路径，与文件树和有界读取使用同一身份；面板按相对工作区根目录的形式标注。点击匹配项走同一条预览链路（滚动到匹配的行列）并收起面板。头部条目在注册时解析会话所属的工作区，并经根条目桥接把预览发布进 frame 独占的预览 store——会话作用域的注册方无法声明根作用域的 store。

Studio 同时提供 `chatFileOpener` 服务，ui-chat 通过 `ctx.get` 读取：当 Studio 被组合时，聊天窗口中的每一个文件手势——工具行的路径链接、产出文件 chip、收尾消息提及——都在万能预览卡片中打开，而不是右侧 Sidebar。opener 将相对路径按当前查看 Session 的工作区根目录解析为绝对路径，按路径决定的 kind 发布 loading → ready/error 流程——产出的 HTML 作为渲染产物在 16:9 舞台上打开，而不是源码，媒体文件不经过文本读取直接打开卡片自带播放器，卡片无法渲染的二进制格式则打开其拒绝提示——仅对源文件携带可选的 focus 行号，失败时以原始原因 reject，使 chat 视图的打开失败对话框原样展示错误。不组合本包即为关闭状态：ui-chat 回退到其 Sidebar 路由。

工作台事项不会因为一次点击就离开客户端。发送控件把该事项的标题、id 与详情写入当前 Session 的输入框草稿——追加在用户已输入的内容之后，因此暂存不会丢弃进行中的草稿——由用户自行发送。卡片状态因此保持不变，因为尚未有任何内容抵达模型；只有「写回」仍然直接发送到聊天，因为该动作的目的就是让模型作答。写回请求要求该事项的整份记录——从开始到现在的完整成果，含后续追加的修正——因为模型再次调用 `workbench_complete` 时会替换该事项先前的记录。待办列表在每个仍可滚动的一端用最后 16px 让卡片渐隐，因此被面板边缘截断的卡片不会被误读为列表的末尾。

每个工作区卡片都会呈现其会话的实时状态：运行中的会话行用进行中状态动画替代会话图标；卡片收起时该动画前置于工作区名称，因为收起会隐藏本该承载它的会话行。

</details>

<a id="model-experience"></a>
## 模型体验

### 文件预览

#### 模型看到的内容

没有直接影响。Studio 预览状态仅存在于浏览器，不进入模型请求；就地保存会通过 Host Remote 写入工作区文件，后续模型请求只会在 agent 读取或用户引用时看到普通文件内容。

#### Token 影响

直接影响为零。

#### KV 缓存影响

独立于模型请求前缀。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

预览有大小限制，图片与视频为只读播放，且只编辑已存在的文本文件；它不会创建、删除、搜索或流式读取大文件。

- **仅限已存在的常规文件**——保存替换 Session 工作区根内已包含的文件；创建、删除与重命名需要其他工具，符号链接被拒绝而不是跟随。
- **保存只做版本守卫，不做合并**——缓冲区读取之后发生变化的文件会被直接拒绝，用户需重新加载并重新应用编辑，而不是自动合并。
- **缓冲区不跨文件保留撤销历史**——卡片为每个打开的文件持有一份缓冲区；关闭或替换预览会直接丢弃未保存的文本，不弹出确认。
- **扩展名标签有限**——未知扩展名显示为纯文本。
- **媒体文件整体读取**——字节以一次 base64 读取传输，受 Host 的整文件上限约束，没有流式或 range 请求，因此更长的文件会报告文件过大无法预览，且浏览器同时持有读取结果、解码后的数组与 blob。
- **媒体预览为只读**——图片与视频在播放器中打开而非编辑器中，因此 SVG 失去就地编辑能力。
- **二进制格式按扩展名拒绝**——拒绝覆盖卡片已知的格式；未知扩展名只有在文本读取解码出非法字节后才被识别为二进制，超过该读取上限的文件仍报告普通的读取失败。
- **目录列表在展开时刷新**——展开一个文件夹会重读它以及它下面所有仍展开的文件夹，但在内容变化时始终保持展开的目录会继续显示它展开时的内容，因为浏览路径没有文件系统 watch。

### 开发备注

<details>
<summary>维护者工作上下文——点击展开</summary>

预览使用已有编辑器槽，因此未来编辑器可以替换展示，而不必增加第二条组合路径；其编辑面是一个基于 workspace-file Remote 的模块（`src/client/preview/edit-face.ts`），因此更丰富的编辑器替换这个带行号的文本框时无需改动框架 store。媒体读取是同一 Remote 上的第二个模块（`src/client/preview/media-face.ts`），因此媒体字节同样不会进入框架 store。
